# Curso HTML5 e CSS3

Projeto desenvolvido para praticar HTML5 e CSS3 com foco em estruturação, responsividade e boas práticas de desenvolvimento web.

## Tecnologias utilizadas
- HTML5
- CSS3

## Objetivos do projeto
- Aprender estrutura semântica
- Melhorar responsividade
- Praticar estilização moderna
- Evoluir na criação de interfaces web

## Status
Projeto em desenvolvimento e aprendizado contínuo.
